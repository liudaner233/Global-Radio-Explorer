# Map assets

基础地图资源随应用部署，近景瓦片仍按当前视野请求。

- `countries.geojson`：Natural Earth 1:110m 国家边界，来自 [natural-earth-vector](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson)。数据为 [公共领域](https://www.naturalearthdata.com/about/terms-of-use/)。
- `earth-blue-marble.jpg`、`earth-night.jpg`、`earth-topology.png`：沿用项目原有的 [three-globe 示例资源](https://github.com/vasturiano/three-globe/tree/master/example/img)，从已安装的 three-globe 包复制。该项目采用 [MIT License](https://github.com/vasturiano/three-globe/blob/master/LICENSE)。
