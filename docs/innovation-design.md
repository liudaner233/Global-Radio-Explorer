# 电台探索：本轮创新设计

本轮参考了以下 9 个代表性国外官网，并非覆盖全部国外网站。目标是让地球探索更有方向、喜欢的信号更容易找回，同时保留连续收听体验。

## 四项新增体验

### 1. 情境与日夜发现

左栏 **Discover** 提供 **World、Focus、Unwind、Energy**，并可叠加 **Sunrise、After dark** 和流派筛选。卡片显示真实国家及匹配标签；**Surprise me** 在当前候选耗尽前避免重复。

情境依据 Radio Browser 已发布的 `station.tags`，不分析当前音频，也不保证节目此刻一定符合标签。日夜依据电台经纬度与当前太阳位置计算；Sunrise 区分日出侧与日落侧，After dark 使用太阳高度低于 −6°的区域。使用的是电台位置，无需取得用户设备 GPS。

### 2. 环球信号旅程

在 Discover 点击 **Start journey**，从当前真实合格候选中生成最多六站的路线，优先不同国家，并考虑相邻地点距离。已有选台若仍符合筛选，可作为首站；地球展示真实站点之间的路线。

通过路线站点或播放器的上一站、下一站**手动切换**。旅程不会定时跳台，拖动地图本身也不会推进路线；结束旅程保留当前播放。候选不足时只展示实际可用的站数，不补造电台。

### 3. 收听护照

右栏 **Passport** 展示累计收听时长、国家足迹和最近二十个电台，可点击重新收听，也可清空记录。

时长依据音频实际播放进度累计；点击电台、缓冲、暂停或静音不计入收听。记录只保存在当前浏览器的本地存储中，不上传、不跨设备同步；清除站点数据会删除记录。重新收听连接当前直播流，不回放当时节目。

### 4. 安静收听与睡眠渐弱

顶部耳机按钮进入 **Quiet listening**，收起两侧栏，保留地球与播放器；退出时恢复侧栏状态。播放器的 **Sleep timer** 可选择十五、三十或六十分钟，最后三十秒逐渐降低实际播放音量，到时暂停；可以取消计时。

计时使用实际截止时间，切台不会重置。浏览器回到前台时重新核对时间；电脑休眠或浏览器冻结期间无法保证在截止瞬间执行，恢复后会补执行暂停。渐弱不覆盖用户保存的音量偏好。

## 数据与范围

发现和旅程来自已经加载的真实地图电台与目录数据，尊重当前流派；候选须具有有效播放地址、合法经纬度和成功的最近检查记录。这是已有元数据筛选，**不是实时在线检测**，实际播放仍可能失败。

无匹配时可切回 World、Any time 或 All。候选不等于全球完整目录，因此不宣称推荐覆盖所有电台；地图、播放器与原有搜索仍可独立使用。
