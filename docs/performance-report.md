# 地球渲染性能检查

本次优化针对国家文字、国家边界、鼠标命中检测及背景动画的持续渲染开销。

## 实测

同一台 AMD Radeon 780M 电脑、Chrome 硬件加速、1366 × 768 视口、1.5 倍像素密度。等待资源加载及开屏扫描结束后，采样八秒全景视图；电台节点与粒子背景开启，未播放音频。复测时没有同时运行构建或测试。以下为优化时的测量记录，测量后已按视觉调整移除国家文字标签。

| 指标                     |    优化前 |     优化后 |
| ------------------------ | --------: | ---------: |
| 平均帧率                 |  11.6 FPS |  119.9 FPS |
| 每帧绘制调用             |   约 1524 |          6 |
| 每帧三角形               | 约 104 万 | 约 12.9 万 |
| 八秒内脚本执行时间       |   7.28 秒 |    1.11 秒 |
| 95% 帧间隔               |  517 毫秒 |   8.6 毫秒 |
| 超过 50 毫秒的主线程任务 |     33 次 |       0 次 |

帧率受屏幕刷新率、设备、视角、电台数量及后台负载影响。此结果针对上述全景场景，不代表所有设备、近景瓦片加载和模型推理期间都能达到相同帧率。

## 原因与修改

- 移除地球上的国家文字图层及对应图集、字形几何、碰撞计算和辅助更新逻辑。国家边界、悬停高亮和点击电台查询仍然保留。
- 国家及岛屿边界原先拆为大量多边形填充、侧面和轮廓物件，即使填充透明也参与绘制。现在用一个 `LineSegments` 批量绘制所有边界，只为悬停或选中国家生成高亮填充。共享边去重，球面细分保留近景线条及日期线正确性。
- 原地图鼠标交互每帧射线检测全场景。现在使用复用的数学球面射线，鼠标移动时每 100 毫秒按需查询国家；拖动不打开面板，电台点击优先于国家点击。
- 扫描期间的节点投影按相机位置缓存，发现状态有变化时才上传 GPU。静止的 6000 节点扫描回归只投影 6001 次；正常呼吸不再重复投影。
- 粒子采用批量 Canvas 填充和描边，限制画布像素预算及刷新率，按绘制耗时调整密度。音浪保留真实 PCM 驱动，限制刷新率并避免无关 React 更新重启动画。

上述图层在页面隐藏时停止辅助更新，并在销毁时释放事件、计时器、几何体及纹理。

## 验证

优化时 TypeScript、ESLint、Prettier 与生产构建通过，前端 268 项、音频网关 40 项测试通过。保留的回归覆盖球面边界、国家点击、拖动、点击优先级、动画预算及资源清理；移除国家文字功能后，对应文字布局测试也已删除。

浏览器确认悬停只高亮、点击国家显示电台面板、拖动不误开面板、重新扫描及近景瓦片正常；检查桌面和手机布局，无 JavaScript 运行时错误。通过真实 Radio Swiss Jazz 直播确认播放时间持续推进，音频解码正常。
